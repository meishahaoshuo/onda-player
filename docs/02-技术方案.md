# 02 技术方案

## 1. 技术栈

| 领域 | 选型 | 版本 | 说明 |
|---|---|---|---|
| 框架 | Vue 3 + TypeScript | ^3.5 | 组合式 API（`<script setup>`） |
| 构建 | Vite | ^7 | dev / build / preview |
| 状态管理 | Pinia | ^3 | player / library / settings 三个 store |
| 文件接入 | File System Access API | 原生 | `showDirectoryPicker` + IndexedDB 存句柄 |
| 元数据 | music-metadata | ^11 | `parseBlob` 解析 File 对象 |
| 本地存储 | idb | ^8 | IndexedDB Promise 封装 |
| 播放 | HTMLAudioElement | 原生 | 单例 audio，队列由 store 管理 |
| 系统集成 | MediaSession API | 原生 | 媒体浮窗 / 媒体键 |

浏览器要求：Chrome / Edge 86+（File System Access API）。页面必须通过 http(s) 访问（`npm run dev` 的 localhost 即可），不支持 `file://` 直接打开。

## 3. IndexedDB 数据模型（库名 `music-player`）

| Object Store | Key | Value | 说明 |
|---|---|---|---|
| `handles` | `root:<id>` | FileSystemDirectoryHandle | 音乐文件夹句柄；`kv` 中存 `folderOrder` 维护顺序 |
| `songs` | `path`（相对根路径） | SongRecord | 全量歌曲元数据 |
| `covers` | `coverId`（专辑名+专辑艺术家哈希） | Blob | 缩略图（256px，JPEG） |
| `playlists` | `id` | PlaylistRecord | 歌单及内含歌曲 path 顺序数组 |
| `kv` | string | unknown | 设置、上次播放状态（队列 path、进度、音量、模式） |

SongRecord 主要字段：

```ts
{
  path: string          // 相对根路径，主键
  rootId: string        // 所属文件夹句柄 id
  fileName: string
  title: string         // 无标签时用文件名
  artist: string        // 多艺术家以 " / " 连接
  album: string         // 无标签时 "未知专辑"
  albumArtist: string
  genre: string
  year: number | null
  trackNo: number | null
  discNo: number | null
  durationSec: number
  bitrateKbps: number | null
  sampleRateHz: number | null
  bitsPerSample: number | null
  container: string     // flac / mp3 / ogg ...
  fileSize: number
  mtimeMs: number       // 用于增量扫描
  hasCover: boolean
  coverId: string | null
}
```

## 4. 关键流程

### 4.1 扫描
1. 从 `handles` 恢复句柄 → `requestPermission` 确认
2. 递归枚举目录（跳过隐藏目录），过滤扩展名得到音频文件清单
3. 与 `songs` 现有记录按 path 对比：大小+mtime 未变的直接跳过；新增/变化的 `parseBlob` 解析；根目录里已消失的删除记录
4. 封面按 `专辑名+专辑艺术家` 去重后缩略并写入 `covers`
5. 扫描在主线程分批执行（每批若干文件让出事件循环），保证 UI 可交互、可取消

### 4.2 播放
- 播放 = `audio.src = URL.createObjectURL(file)`（由句柄实时 `getFile()`），播完按模式决定下一曲
- 队列是 path 数组 + 当前索引；随机播放洗牌但不重复直到一轮结束
- MediaSession：`metadata`（标题/艺术家/专辑/封面 artwork）+ 四个 action handler
- 刷新恢复：从 `kv` 读队列与进度，恢复后处于暂停态等待用户点击播放

### 4.3 歌词
- 播放时尝试读取同目录 `<同名>.lrc`，按 `[mm:ss.xx]` 解析时间轴
- 时间戳差 < 50ms 的相邻行合并为一组（原文 + 翻译/罗马音）
- 无歌词或解析失败则歌词页显示占位文案

## 5. 已知限制

- APE / TTA 等浏览器不支持的格式无法播放，扫描时跳过并计入"已跳过"数量
- 网页无法做到窗口级磨砂（透出桌面），磨砂只作用于页面内部
- 浏览器标签页关闭后句柄权限需确认一次（浏览器安全机制，无法绕过）
