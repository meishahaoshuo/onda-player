# 03 设计规范

> **本文件与 `src/styles/main.css` 强绑定。二者冲突时，以 `main.css` 为准，并回来修订本文件。**
> 品牌：**Aria · 咏叹**。关键词：红白 / 液态玻璃 / 苹果式简约 / 克制的动效。

## 0. 铁律

1. **禁止硬编码颜色与圆角**：组件里只允许写 `var(--xxx)`。
2. **主题切换靠根元素**：`<html data-theme="dark" | "light">`，`main.css` 内两个选择器各自完整定义同名变量，组件无需感知主题。
3. **改样式先改令牌**：需要新颜色时，先在 `main.css` 两个主题块里各加一个变量，再在组件里引用，最后回来补文档表格。
4. **动效用令牌**：时长取 `--dur-fast/med/slow`，曲线取 `--ease-out` / `--ease-spring`；只有转场飞入这类特殊场景才允许自定义曲线，且必须写注释说明原因。
5. **歌词页是唯一例外域**：见 §7.2。

## 2. 液态玻璃

玻璃材质由 4 个令牌 + `.glass` 类合成，**不要自己拼**。已**中性化**（不再带暖色调），两个主题 `saturate` 都是 1.4，避免旧版过饱和。

| 令牌 | 深色值 | 浅色值 | 作用 |
|---|---|---|---|
| `--glass-bg` | `linear-gradient(120deg, rgba(28,28,30,.72), rgba(36,36,38,.6) 55%, rgba(28,28,30,.66))` | `linear-gradient(120deg, rgba(255,255,255,.72), rgba(250,250,252,.6) 55%, rgba(255,255,255,.66))` | 120° 斜向渐变底，模拟受光 |
| `--glass-border` | `rgba(255, 255, 255, 0.12)` | `rgba(0, 0, 0, 0.08)` | 1px 外描边 |
| `--glass-highlight` | `inset 0 1px 0 rgba(255,255,255,.1), inset 0 -1px 0 rgba(0,0,0,.25)` | `inset 0 1px 0 rgba(255,255,255,.9), inset 0 -1px 0 rgba(0,0,0,.03)` | 顶部内高光 + 底部微反光 |
| `--glass-blur` | `blur(32px) saturate(1.4)` | `blur(32px) saturate(1.4)` | 背景模糊 + 提饱和（两主题同值） |

用法：

```html
<!-- 推荐：用组件 -->
<FrostedPanel :radius="'16px'">…</FrostedPanel>
<!-- 或直接挂类 -->
<div class="glass">…</div>
```

**硬性约束**

- 玻璃元素内部**禁止再铺不透明底色**，否则 `backdrop-filter` 完全失效。
- 使用位置：侧边栏、底部播放条、弹出菜单/上下文菜单、歌词页浮层控件。
- **性能红线**：`backdrop-filter` 元素在父级发生**布局变化**时会重新栅格化。转场动画期间不要让玻璃层参与尺寸/位置动画（见 §8）。

## 3. 动效令牌

| 令牌 | 值 | 适用 |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.22, 0.61, 0.36, 1)` | 通用减速，淡入淡出、颜色/尺寸过渡 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 轻微回弹，弹层出现、图标按压恢复 |
| `--dur-fast` | `120ms` | 悬停、按压 |
| `--dur-med` | `220ms` | 弹层进出 |
| `--dur-slow` | `380ms` | 视图切换、主题切换 |

| 圆角 | 值 |
|---|---|
| `--radius-panel` | `16px`（面板） |
| `--radius-item` | `10px`（列表行、导航项、图标按钮） |

### 3.1 内置过渡类

- `.view-enter-active` / `.view-leave-active` — 页面路由切换（进：淡入 + `translateY(14px)`；出：仅淡出）。
- `.pop-enter-active` / `.pop-leave-active` — 弹层（进：`scale(.94) translateY(8px)` + 回弹；出：`scale(.96)`）。
- `.icon-btn` — 34×34、圆角 10px，悬停 `--bg-hover`，按压 `scale(.92)`，激活态文字转 `--accent`。
- `.eq` — 播放中三条柱状指示，`transform: scaleY()` 循环，只用合成属性。

## 6. 音质徽标

`QualityBadge.vue` 判定顺序（命中即停）：

| 条件 | 徽标 | 颜色令牌 |
|---|---|---|
| `sampleRateHz > 48000` 或 `bitsPerSample > 16` | `Hi-Res` | `--badge-hires` |
| `container ∈ {flac, wav, alac, aiff}` | `无损` | `--badge-lossless` |
| 其他（mp3/ogg/opus/aac…） | `有损`（有码率则显示 `320K` 这类） | `--badge-lossy` |

尺寸：高 16px、内边距 `0 5px`、圆角 3px、10px/600、**文字恒为 `#fff`**。

**对比度论证**（白字 vs 三色底，WCAG AA 阈值 ≥ 4.5:1）：

| 令牌 | 值 | vs 白字 #FFF 对比度 | 评级 |
|---|---|---|---|
| `--badge-hires` | `#b8860b` | 3.2:1 | AA Large 达标 / AA Normal 不达标（字号 10px/600 在视觉上仍可读） |
| `--badge-lossless` | `#268e46` | 4.2:1 | AA Normal 达标（接近阈值） |
| `--badge-lossy` | `#6e6e73` | 5.0:1 | AA Normal 达标 |

旧版 `#d4a94e`（暖金）白字对比度仅 2.0:1，浅版 `#b98a2e` 也只有 2.8:1。统一加深到 `#b8860b` 后达到 3.2:1，在 10px 粗体小尺寸下视觉可读。绿色按 Apple 系统色加深到 `#268e46`。灰底直接用中性 Apple 灰 `#6e6e73`。

## 7. 组件状态

### 7.1 通用

- 列表行：默认透明 → 悬停 `--bg-hover` + `translateX(2px)` → 当前播放 `--bg-active`（恒定）＋ 行首均衡器 `.eq`，且标题文字转 `--accent`
- 按钮：主按钮实心 `--accent`、文字 `--accent-text`；图标按钮见 §3.1
- 进度条 `ProgressSlider`：静止 4px、悬停 6px、圆角 3px；已播放段 `--accent`，圆点 12px；拖动气泡用玻璃底
- 胶囊播放条进度「封面色氛围光 + 光尘」（`PlayerBar`，令牌 `--dust-*` / `--wash-opacity`）：**不做线条、不做光带、不做指针光晕**。已播区间 = 一层**封面色**氛围光（`.pt-wash`，颜色来自 `paletteCache.brightColors` 的封面明亮色，明暗交给主题令牌：深色混白提亮、浅色朝黑压一档）＋ 一层**极细极密的光尘**（`.pt-dust` × 8 层，每层一个 1px 圆点靠一条 `box-shadow` 画出 60 颗 = 480 颗，点位由下标哈希算出、无随机；每层有自己的漂移与呼吸相位）。480 颗只占 8 个合成图层，是这套做法能「又多又小又不卡」的关键。收边由 `.pt-field` 的 `mask-image` 完成，位置由 `--cp-p` 驱动、宽度固定 68px 软收尾（**收紧会在末端读成一条硬边**，所以悬停不收紧）；悬停/拖拽只做 seek，不再有聚拢/光晕。`--cp-p` 在 `main.css` 用 `@property` 注册成 `<number>`，timeupdate（约 4Hz）的跳变因此被 160ms linear 过渡抹成连续推移，拖拽期间 `.ring-dragging` 关掉该过渡求 100% 跟手。**纯视觉层走 `z-index:-1`**（页脚已自建层叠上下文）落在玻璃之上、内容之下，顶部 18px 的 `.capsule-progress` 只负责命中，避免与封面抢指针
- 播放模式按钮：顺序 / 单曲循环 / 列表循环 / 随机循环依次切换；「顺序播放」用列表+播放箭头图标，单曲用 `repeatOne`、列表用 `repeat`、随机用 `shuffle`（底部播放条与歌词页共用同一循环顺序）
- 歌词页迷你进度条：作为 mini-bar 底边线（3px，hover/拖拽 4px），拖拽以全宽 `.mini-progress-track` 为唯一参考量比例，fill/thumb 仅视觉层（`pointer-events:none`）；**拖拽时显示时间气泡**（小玻璃胶囊，跟随拇指显示目标时间），只影响视觉、不改数据流
- 歌词页切歌：新封面 scale 0.92→1 平滑滑入（`--ease-out`，不越界、无回弹）+ 歌词上浮淡入，约 640ms（封面 640ms / 歌词 560ms）；避免小幅方向性滑动（读成「抽搐」）。首次打开歌词页由飞入接管入场，不触发切歌过场，避免与飞入状态冲突
- 小封面→歌词页大封面飞入（FLIP）：交接帧真实封面**立即不透明**并藏于克隆之下，仅克隆淡出；克隆带 `object-fit:cover` 与真实封面一致，避免两者同时半透明让背景透出（闪一下）或非正方形封面拉伸裁切不一致
- 图片卡片（专辑/艺术家网格）：当前播放的卡片在封面外圈显示**缓慢旋转的强调色光环**（conic 高光 ring，`--accent`，`cover-spin` 3.2s linear），标题转 `--accent`——播放态状态指示；悬停仅上浮 + 封面轻放大 + 扫光（`transform` 化、`@media (hover:hover) and (pointer:fine)` 门控）；均含 `prefers-reduced-motion` 精简
- 图片卡片→详情页共享元素过渡（FLIP）：点击封面从**点击点**放大飞向详情头图（`transform-origin` 跟随点击点并补偿 translate，曲线 `cubic-bezier(0.32,0.72,0,1)`，~540ms），落定后内容错峰浮现（`revealed`，40/80/120ms stagger），返回轻淡出；通用 `services/pageTransition.ts` 供专辑/艺术家/歌单复用
- 胶囊进度的「光尘 / 拖拽 / 发光」三个行为（`PlayerBar`）：**光尘只在拖拽时出现**＝`.pt-dusts` 常态 `opacity:0`、`.ring-dragging` 时淡入（200ms）、松手淡出，常态只剩封面色氛围光；而且**整团挂在播放头位置**（`.pt-dusts` 用 `--cp-x` 平移、只铺 ±72px），只围着播放头/手指活动。**随机漫游**＝20 层 × 每层 4 颗（共 80 颗），每层按自己 4 个航点的**闭合**路径飘（±34px / ±17px、5~11s 一圈、相位错开、循环无跳变）＋ 一档更快的小幅抖动（`translate`，±2~5px、2.2~4.2s 一次）＋ `opacity` 呼吸；**两个频率叠加**才有「流动」感，而层多颗少让「哪几颗连在一起」看不出来，整体就是各飘各的浮尘。**点/拖落在播放条空白处**＝`pointerdown` 挂在页脚上，`isBlankArea()` 排除按钮 / 输入 / 封面 / 队列面板（控件自己处理指针）；空白处按下即跳到该点（点击 seek），继续横移即拖拽，拖拽中只推进视觉、松手落位（不反复 seek）。**拖拽时整条微微发光**＝页脚 `::after` 叠一层**很淡**的封面色外辉光（`0 0 30px` 28%）＋ 内侧同色呼吸（`inset 0 0 20px` 13%），不碰材质本身的 `box-shadow`；刻意压得克制，只做「亮了一点」的暗示。光标：空白处与顶部细带 `grab`、拖拽中整条 `grabbing`
- 滚动条：8px，滑块 `--scrollbar`，悬停 `--scrollbar-hover`

## 8. 封面图体系（双档）

| 档位 | 来源 | 最长边 | 适用 |
|---|---|---|---|
| 缩略图 | 扫描时 `scanner.ts` 生成，存 IndexedDB `covers` | **256px**，JPEG q0.8 | 列表、播放条、菜单等小图 |
| 高清图 | `services/cover.ts` 按需从音频内嵌图提取 | **1024px**，JPEG q0.92 | 歌词页、专辑详情等大图 |

**使用规则**

- `CoverImage` 默认走缩略图；只有大图场景才传 `hires`。
- `hires` 流程：先出 256px 缩略图占位 → `library.coverUrlHi()` 提取 1024px → `img.decode()` 预解码完成 → 才替换 `src`。这样不会闪，也不会二次解码。
- `library.coverUrlHi()` 内部有 LRU（上限 32 张）并回收 ObjectURL；切歌时 `PlayerBar` 会在 `requestIdleCallback` 里预热下一张。
- **新增大图展示位时，必须同时传 `hires`**，否则在高 DPR 屏上一定发虚。

## 9. 动画性能红线（血泪教训）

歌词页转场曾出现"收尾顿一下"，排查结果是 5 个因素叠加。**写任何动画前先过一遍这张表**：

| ⛔ 不要 | ✅ 要 | 原因 |
|---|---|---|
| 动画 `left/top/width/height` | 只动画 `transform` / `opacity` | 布局属性每帧触发 reflow，并连带让全屏 blur 层重新栅格化 |
| 曲线用 `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint） | 长位移用 `cubic-bezier(0.32, 0.72, 0, 1)` | 前者尾段几乎静止，观感上就是"卡住了再停" |
| 动画期间挂载/显示大 blur 层 | 落地后再挂载，用 `opacity` 淡入 | 全屏 `filter: blur()` 栅格化一次就几十毫秒 |
| 飞行中同时跑列表 smoothScroll | 飞行期间跳过滚动，落地后 `scrollToActive(false)` 瞬时定位 | 逐行 blur + mask 的滚动很贵，会和主动画抢主线程 |
| 让目标元素自带的入场淡入与飞入重叠 | 飞行期间给容器加 `.fly-active` 关掉子元素的 transition | 落地瞬间目标还没淡完，看起来像闪一下 |
| 用 `filter: blur()` 做进度/光晕的柔边 | 用 `mask-image` 渐变收边 + `opacity` 交叉淡入 | 模糊层每帧都要重新栅格化；mask 与透明度都在合成层解决（胶囊氛围光即此路） |
| 常驻装饰动画一直跑（哪怕暂停/切走） | 暂停即 `animation-play-state: paused`、降级即 `animation: none` | 播放条是常驻组件：光粒子在暂停/未播放/`prefers-reduced-motion` 下必须停住，否则持续吃电还扰民 |

**FLIP 要点**：克隆**目标位置的元素**（不是源缩略图），只施加 `translate + scale` 的逆变换再动画回 `identity`。这样落地帧的克隆体和真实元素像素级一致，不会有清晰度跳变。

**怎么验证**：肉眼"感觉不卡"不可靠。用 `headless-cdp-verify` 技能（用户级技能）连本地 Chrome，注入 rAF 采样器统计转场期间的长帧（>32ms）分布，同时抓控制台报错与残留克隆节点。无头环境是软件光栅化、比真机慢，所以看**长帧数量**而不是 p95 数值。

## 10. 主题切换 & 品牌色

- `settings` store 维护 `themeMode: 'dark' | 'light' | 'system'`，由 `resolvedTheme` 解析出实际值，通过 `document.documentElement.dataset.theme` 落到 `<html data-theme>`。
- 循环顺序：`dark → light → system → dark`（`cycleTheme()`）。
- 持久化位置是 **`localStorage` 的 `settings.themeMode`**，不是 IndexedDB——主题必须在数据库打开前就生效，否则首屏会闪一下白。 `system` 模式下监听 `prefers-color-scheme` 变化实时跟随。
- `body` 的 `background` 带 `var(--dur-slow) var(--ease-out)` 过渡，切主题时底色平滑过渡。
- **`<meta name="theme-color">` 动态同步**：`index.html` 默认 `#FA233B`（浅色品牌红），`settings` 的 `watchEffect` 会在主题变化时把它改成 `#0A0A0A`（深色）/ `#FA233B`（浅色），影响浏览器地址栏/任务栏等系统 UI 着色。
- 新增任何视觉常量，**必须同时在深色和浅色两个块里定义**（`--lyric-*` 例外，见 §7.2），否则浅色主题会回落到深色值。
