# 03 设计规范

> **本文件与 `src/styles/main.css` 强绑定。二者冲突时，以 `main.css` 为准，并回来修订本文件。**
> 品牌：**Aria · 咏叹**。关键词：暖色 / 液态玻璃 / 苹果式简约 / 克制的动效。

## 0. 铁律

1. **禁止硬编码颜色与圆角**：组件里只允许写 `var(--xxx)`。唯一例外是歌词页覆盖在图片背景上的纯白文字（见 §7.2）。
2. **主题切换靠根元素**：`<html data-theme="dark" | "light">`，`main.css` 内两个选择器各自完整定义同名变量，组件无需感知主题。
3. **改样式先改令牌**：需要新颜色时，先在 `main.css` 两个主题块里各加一个变量，再在组件里引用，最后回来补文档表格。
4. **动效用令牌**：时长取 `--dur-fast/med/slow`，曲线取 `--ease-out` / `--ease-spring`；只有转场飞入这类特殊场景才允许自定义曲线，且必须写注释说明原因。

## 2. 液态玻璃

玻璃材质由 4 个令牌 + `.glass` 类合成，**不要自己拼**。

| 令牌 | 深色值 | 作用 |
|---|---|---|
| `--glass-bg` | `linear-gradient(120deg, rgba(46,37,30,.55), rgba(38,30,24,.38) 55%, rgba(46,36,28,.5))` | 120° 斜向渐变底，模拟受光 |
| `--glass-border` | `rgba(255, 234, 210, 0.14)` | 1px 外描边 |
| `--glass-highlight` | `inset 0 1px 0 rgba(255,240,220,.22), inset 0 -1px 0 rgba(255,240,220,.05)` | 顶部内高光 + 底部微反光 |
| `--glass-blur` | `blur(32px) saturate(1.7)`（浅色 `1.6`） | 背景模糊 + 提饱和 |

用法：

```html
<!-- 推荐：用组件 -->
<FrostedPanel :radius="'16px'">…</FrostedPanel>
<!-- 或直接挂类 -->
<div class="glass">…</div>
```

**硬性约束**

- 玻璃元素内部**禁止再铺不透明底色**，否则 `backdrop-filter` 完全失效。
- 使用位置：侧边栏、底部播放条、弹出菜单/上下文菜单、歌词页浮层控件。
- **性能红线**：`backdrop-filter` 元素在父级发生**布局变化**时会重新栅格化。转场动画期间不要让玻璃层参与尺寸/位置动画（见 §8）。

## 3. 动效令牌

| 令牌 | 值 | 适用 |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.22, 0.61, 0.36, 1)` | 通用减速，淡入淡出、颜色/尺寸过渡 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 轻微回弹，弹层出现、图标按压恢复 |
| `--dur-fast` | `120ms` | 悬停、按压 |
| `--dur-med` | `220ms` | 弹层进出 |
| `--dur-slow` | `380ms` | 视图切换、主题切换 |

| 圆角 | 值 |
|---|---|
| `--radius-panel` | `16px`（面板） |
| `--radius-item` | `10px`（列表行、导航项、图标按钮） |

### 3.1 内置过渡类

- `.view-enter-active` / `.view-leave-active` — 页面路由切换（进：淡入 + `translateY(14px)`；出：仅淡出）。
- `.pop-enter-active` / `.pop-leave-active` — 弹层（进：`scale(.94) translateY(8px)` + 回弹；出：`scale(.96)`）。
- `.icon-btn` — 34×34、圆角 10px，悬停 `--bg-hover`，按压 `scale(.92)`，激活态文字转 `--accent`。
- `.eq` — 播放中三条柱状指示，`transform: scaleY()` 循环，只用合成属性。

## 7. 组件状态

### 7.1 通用

- 列表行：默认透明 → 悬停 `--bg-hover` + `translateX(2px)` → 当前播放 `--bg-active`（恒定）＋ 行首均衡器 `.eq`，且标题文字转 `--accent`
- 按钮：主按钮实心 `--accent`、文字 `--accent-text`；图标按钮见 §3.1
- 进度条 `ProgressSlider`：静止 4px、悬停 6px、圆角 3px；已播放段 `--accent`，圆点 12px；拖动气泡用玻璃底
- 滚动条：8px，滑块 `--scrollbar`，悬停 `--scrollbar-hover`

### 7.2 已知例外

- 歌词页文字压在封面提取的渐变背景上，无法预知底色，因此 `.lyric-text` 直接使用 `rgba(255,255,255,.88)` / `#fff` 等纯白值。**这是本项目唯一允许的颜色硬编码**，不要"顺手"改成变量。

## 8. 封面图体系（双档）

| 档位 | 来源 | 最长边 | 适用 |
|---|---|---|---|
| 缩略图 | 扫描时 `scanner.ts` 生成，存 IndexedDB `covers` | **256px**，JPEG q0.8 | 列表、播放条、菜单等小图 |
| 高清图 | `services/cover.ts` 按需从音频内嵌图提取 | **1024px**，JPEG q0.92 | 歌词页、专辑详情等大图 |

**使用规则**

- `CoverImage` 默认走缩略图；只有大图场景才传 `hires`。
- `hires` 流程：先出 256px 缩略图占位 → `library.coverUrlHi()` 提取 1024px → `img.decode()` 预解码完成 → 才替换 `src`。这样不会闪，也不会二次解码。
- `library.coverUrlHi()` 内部有 LRU（上限 32 张）并回收 ObjectURL；切歌时 `PlayerBar` 会在 `requestIdleCallback` 里预热下一张。
- **新增大图展示位时，必须同时传 `hires`**，否则在高 DPR 屏上一定发虚。

## 9. 动画性能红线（血泪教训）

歌词页转场曾出现"收尾顿一下"，排查结果是 5 个因素叠加。**写任何动画前先过一遍这张表**：

| ⛔ 不要 | ✅ 要 | 原因 |
|---|---|---|
| 动画 `left/top/width/height` | 只动画 `transform` / `opacity` | 布局属性每帧触发 reflow，并连带让全屏 blur 层重新栅格化 |
| 曲线用 `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint） | 长位移用 `cubic-bezier(0.32, 0.72, 0, 1)` | 前者尾段几乎静止，观感上就是"卡住了再停" |
| 动画期间挂载/显示大 blur 层 | 落地后再挂载，用 `opacity` 淡入 | 全屏 `filter: blur()` 栅格化一次就几十毫秒 |
| 飞行中同时跑列表 smoothScroll | 飞行期间跳过滚动，落地后 `scrollToActive(false)` 瞬时定位 | 逐行 blur + mask 的滚动很贵，会和主动画抢主线程 |
| 让目标元素自带的入场淡入与飞入重叠 | 飞行期间给容器加 `.fly-active` 关掉子元素的 transition | 落地瞬间目标还没淡完，看起来像闪一下 |

**FLIP 要点**：克隆**目标位置的元素**（不是源缩略图），只施加 `translate + scale` 的逆变换再动画回 `identity`。这样落地帧的克隆体和真实元素像素级一致，不会有清晰度跳变。

**怎么验证**：肉眼"感觉不卡"不可靠。用 `headless-cdp-verify` 技能（用户级技能）连本地 Chrome，注入 rAF 采样器统计转场期间的长帧（>32ms）分布，同时抓控制台报错与残留克隆节点。无头环境是软件光栅化、比真机慢，所以看**长帧数量**而不是 p95 数值。

## 10. 主题切换

- `settings` store 维护 `themeMode: 'dark' | 'light' | 'system'`，由 `resolvedTheme` 解析出实际值，通过 `document.documentElement.dataset.theme` 落到 `<html data-theme>`。
- 循环顺序：`dark → light → system → dark`（`cycleTheme()`）。
- 持久化位置是 **`localStorage` 的 `settings.themeMode`**，不是 IndexedDB——主题必须在数据库打开前就生效，否则首屏会闪一下白。 `system` 模式下监听 `prefers-color-scheme` 变化实时跟随。
- `body` 的 `background` 带 `var(--dur-slow) var(--ease-out)` 过渡，切主题时底色平滑过渡。
- 新增任何视觉常量，**必须同时在深色和浅色两个块里定义**，否则浅色主题会回落到深色值。
