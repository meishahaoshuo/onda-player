# 03 设计规范

所有颜色/模糊/尺寸均以 CSS 变量定义在 `src/styles/main.css`，组件只允许引用变量，不允许硬编码颜色。主题切换 = 根元素切换 `data-theme="dark" | "light"`。

## 2. 磨砂面板（FrostedPanel）

- 实现：半透明底色 + `backdrop-filter: blur(20px) saturate(1.2)` + 1px `--border-subtle` 描边 + 大圆角
- 使用位置：侧边栏、底部播放条、弹出菜单/上下文菜单、全屏歌词页的浮层控件
- 注意：`backdrop-filter` 需要元素背景整体半透明，禁止在磨砂元素内再嵌不透明底色

## 3. 布局尺寸

| 区域 | 规格 |
|---|---|
| 页面 | `100vh` 三段式：内容区 flex:1，播放条固定底部高 72px |
| 侧边栏 | 宽 224px，磨砂，导航项高 40px、圆角 8px、选中态 `--bg-active` + 左侧 3px 强调色条 |
| 歌曲列表行 | 高 56px；封面 40×40 圆角 4px |
| 专辑详情封面 | 192×192，圆角 8px，带投影 |
| 全屏歌词封面 | 尺寸 `min(42vh, 42vw)`，居中，圆角 12px |
| 歌词行距 | 原文行 28px 字号 / 翻译行 16px 字号；行间距 28px |

## 4. 字体

- 字族：`'Segoe UI', 'Microsoft YaHei', system-ui, sans-serif`
- 主文字 14px；列表次要列 13px；页面标题 22px semibold；歌词当前行 28px semibold

## 5. 音质徽标规则

| 条件 | 徽标 |
|---|---|
| sampleRate > 48000 或 bitsPerSample > 16 | `Hi-Res` |
| container ∈ {flac, wav, alac} | `无损` |
| 其他（mp3/ogg/opus/aac） | `有损`（显示码率，如 320K） |

## 6. 组件状态

- 列表行：默认透明 → 悬停 `--bg-hover` → 当前播放 `--bg-active`（恒定）+ 行尾勾选图标
- 按钮：主按钮实心 `--accent`；图标按钮 32×32、悬停 `--bg-hover`
- 进度条：高 4px 圆角，悬停变 6px，已播放部分 `--accent`
- 滚动条：8px 半透明圆角，悬停加深
