# 01 需求说明

本项目是一个运行在浏览器中的本地音乐播放器（对标 Salt Player 桌面版），用户选择本地音乐文件夹后，在网页内完成浏览、管理和播放。所有数据仅存于本地浏览器，不上传任何内容。

## 1. 核心需求

### 1.1 音乐库接入
- 选择本地音乐文件夹（支持多文件夹），浏览器「记住」授权，重开页面后确认一次权限即可恢复，文件不复制
- 递归扫描文件夹内的音频文件，解析标签（标题/艺术家/专辑/曲风/年份/音轨号/碟片号）
- 支持格式：MP3 / FLAC / OGG / OPUS / WAV / M4A（APE 等浏览器不支持的格式明确跳过）
- 读取内嵌封面，缩略图缓存到 IndexedDB
- 增量扫描：按「路径 + 文件大小 + 修改时间」判断文件是否变化，未变化的不重复解析
- 扫描过程显示进度，可随时取消；扫描不阻塞界面交互

### 1.2 音乐库浏览（对照截图 2）
- 左侧边栏导航：歌曲 / 曲风 / 专辑 / 艺术家 / 文件夹 / 新建歌单 / 歌单列表 / 设置
- 歌曲列表列：封面缩略图、音质徽标（Hi-Res / 无损 / 有损）、标题、艺术家、专辑、时长
- 列表支持排序；大库（数千首）滚动不卡顿（虚拟滚动）
- 当前播放歌曲整行高亮 + 行尾勾选图标

### 1.3 专辑详情页（对照截图 3）
- 头部：大封面、专辑名、艺术家、歌曲数/总时长/年份
- 操作：播放全部、随机播放、列表循环
- 曲目按碟片号分组展示，当前播放高亮

### 1.4 播放内核
- 播放 / 暂停 / 上一曲 / 下一曲 / 进度拖拽 / 音量调节
- 播放模式：顺序播放 / 列表循环 / 单曲循环 / 随机播放
- 播放队列可见、可跳转
- MediaSession API：Windows 媒体浮窗与媒体键可控
- 状态持久化：刷新/关闭后恢复队列、当前曲目、进度、音量、播放模式

### 1.5 全屏歌词页（对照截图 1）
- 背景：当前封面铺满 + 大半径高斯模糊 + 压暗层
- 封面居中显示，下方带倒影
- 逐行歌词：当前行放大高亮，其余行按距离递减透明度；歌词随播放自动居中滚动
- 双语歌词：读取同目录同名 .lrc；时间戳相同的行（翻译/罗马音）合并为一组渲染
- 点击任意歌词行跳转播放进度

### 1.6 歌单
- 新建 / 重命名 / 删除歌单；添加歌曲；拖拽排序；歌单整体播放

### 1.7 设置页
- 音乐文件夹管理（查看 / 添加 / 移除 / 重新扫描）
- 主题：跟随系统 / 深色 / 浅色；强调色选择

## 2. 非功能需求

- **主题**：深色 / 浅色 / 跟随系统三模式，切换即时生效并持久化
- **视觉**：磨砂半透明面板（backdrop-filter），深色为深蓝黑色调、浅色为浅灰白色调（详见 03-设计规范）
- **性能**：万首级歌库可用；首次扫描显示进度
- **隐私**：零网络请求，所有数据仅本地
- **浏览器**：Chrome / Edge 最新版（依赖 File System Access API）
