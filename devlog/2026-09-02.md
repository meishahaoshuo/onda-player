## 第二轮：歌词页与播放器交互体验修复（7 项）

### 改动
1. **飞入落地闪一下 + 背景黑边/缓慢铺开**：`.bg-ambient` 呼吸动画改为 `scale(1 → 1.06)`（只放大不缩小），四周不再露黑边；`flyIn` 拿到高清 URL 后先 `preloadImage` 并写入真实 `.cover-main img` 的 `src` 再克隆，落地克隆与真实封面是同一张高清图（无清晰度跳变）；`settleFly` 同一 rAF 内恢复真实封面并移除克隆、下一帧才清 `fly-active`。
2. **迷你进度条不可用**：`.mini-progress-fill`/`.mini-progress-thumb` 设为纯视觉层（`pointer-events:none`），指针事件只绑在 `.mini-progress-track`；`ratioFromPointer` 始终量全宽 track 矩形；拖拽用 `dragPct`（0-100）驱动 fill/thumb 即时跟手，松手交还给 `progressPct`。
3. **静音后音量不恢复**：`player` store 新增 `lastVolume` 与 `toggleMute()`（静音记录当前值、取消恢复上次值），mini-bar 音量按钮改调 `toggleMute`。
4. **背景取色观感**：`renderAmbientUrl` 烘焙参数改为 `blur(6px) saturate(1.06)`、焦点半径加大、放宽近白块跳过、压暗改为 120-230 平滑过渡（亮封面不再一刀切压暗）。
5. **播放模式顺序**：循环重排为 顺序→单曲→列表→随机（单曲一次点击即达）；`icons.ts` 新增 `order` 图标（列表+播放箭头）；歌词页与底部播放条 `MODE_META` 同步。
6. **歌词与底部栏重叠**：`.main` 底部预留 `112px`（24px 距离 + 迷你条约 70px + 间隙），`.lyric-scroll` 不再衬到迷你条后面。
7. **切歌过场**：改为方向性淡化+滑动（封面左移滑出 `translateX(-24px)`、歌词右移滑入 `translateX(24px)`，380ms + ease/spring），读作「封面滑出、歌词滑入」。

### 追加：切歌动画改为「spring 弹入」（用户反馈太快/像抽搐）
- 原方向性滑动（封面左移滑出、歌词右移滑入 ±24px）幅度小且快，读感像抽搐。改为：新封面从 `scale(0.9) opacity .7` 用 `--ease-spring` 弹回 `scale(1)/1`，歌词从 `translateY(18px) opacity .7` 上浮淡入，时长约 520ms（`switching` 提前到 520ms 后再归位）。
- 验证：CDP 抓 120/270/470/870ms 帧，弹入节奏居中舒展、落定无重叠、无 console 错误；`vue-tsc` + `vite build` 通过。

### 追加：切歌再放慢 + 修复飞入结尾抽搐/闪（用户反馈仍太快/结尾闪）
- **切歌**：时长 520→640ms（封面 transform 640ms spring / opacity 460ms，歌词 560ms ease-out），封面从 `scale(0.92) opacity .55` 归位，更优雅灵动。
- **飞入结尾闪一下根因**：`currentPath` watcher `immediate:true` 在**首次打开**也会把 `switching` 置 true（约 520ms），与飞入 `fly-active` 同时作用在 `.cover-main`；飞入结束、`fly-active` 移除的瞬间若 `switching` 仍在，封面被 `scale(0.9)` 压回再归位 → 抽搐/闪。修复：加 `currentPathFirstRun`，首次挂载不触发切换过场（由 `flyIn` 接管入场）。
- **飞入交接**：`settleFly` 改为交叉淡化（克隆 120ms 淡出、真实封面 120ms 淡入，再清除 `fly-active`），mask 任何镜像/内容差异。
- 验证：页面内 rAF 采样 94 点，落地无 0→1 硬跳（`hardJump=null`）、封面 transform 始终单位阵（`scaleDip=null`）、末态 opacity=1；切歌慢版中间帧/落定帧正常；无 console 错误；`vue-tsc` + `vite build` 通过。

### 追加：定位并修复飞入结尾「闪一下」真正的两个根因
- **透明度衰减**：此前交接让「克隆淡出 + 真实封面淡入」同时进行，两者中间帧都半透明，背景从底下透出导致亮度坍缩（闪一下）。改为：交接帧真实封面**立即不透明**（藏于克隆之下），只淡出克隆（120ms）。诊断确认克隆存在期间真实封面恒为不透明（`imgNotOpaqueDuringClone=0`），无亮度塌缩。
- **object-fit 不一致**：克隆是裸 `<img>` 挂到 body，缺 `object-fit`，非正方形封面会以 `fill` 拉伸变形、与真实封面的 `cover` 裁切不同 → 交接内容跳变。给克隆补 `objectFit:'cover'`（诊断确认 `cloneFit=cover`）。
- 验证：逐帧诊断交接窗，克隆单侧淡出 1→0、真实封面始终 op=1、`cloneFit=cover`；无 console 错误；`vue-tsc` + `vite build` 通过。
