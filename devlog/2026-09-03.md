## Bug 修复：歌曲列表表头列与行列错位

### 现象（截图）
用户反馈：列表页顶部的「标题/艺术家/专辑/时长」表头和下面行实际内容的位置对不上，整体往左错了一格。

### 根因
`src/components/SongList.vue`：
- `.list-header` 和 `.song-row` 共用同一个 5 列 grid：`56px / minmax(0,2.2fr) / minmax(0,1fr) / minmax(0,1.2fr) / 72px`（封面 / 标题 / 艺术家 / 专辑 / 时长）
- 但 `.list-header` 里只有 4 个 `<span>`（col-title / col-artist / col-album / col-duration），**漏了第 1 列的封面占位**
- 结果 CSS Grid auto-placement 把「标题」塞进 56px 封面格里，后 3 列整体往左错 1 格，对应到行就完全对不上

### 修复
给 `.list-header` 加一个空的 `<span class="col-cover" aria-hidden="true"></span>` 占位，与行 5 列对齐。

```diff
 <div class="list-header">
+  <span class="col-cover" aria-hidden="true"></span>
   <span class="col-title">标题</span>
   <span class="col-artist">艺术家</span>
   <span class="col-album">专辑</span>
   <span class="col-duration">时长</span>
 </div>
```

一处修复覆盖所有用 `<SongList>` 的页面：SongsView / AlbumDetailView / ArtistsView / GenresView / FoldersView / PlaylistsView（5 个视图共用一个子组件）。
