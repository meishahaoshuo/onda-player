# 2026-09-05 开发日志

## 今日完成
- **新增通用共享元素过渡**（`src/services/pageTransition.ts`）：`capturePageTransition(cover, clickPoint)` 在点击卡片时克隆被点封面、记录矩形与点击点；`playPageTransition(target)` 从终点矩形做 FLIP，`transform-origin` 设为点击点并补偿 translate，让封面从**点击处生长**而非中心缩放，末帧精确落在详情头图；曲线 `cubic-bezier(0.32,0.72,0,1)` ~540ms，落定用「目标立即不透明 + 克隆 120ms 淡出」避免亮度坍缩；`prefers-reduced-motion` 下直接 resolve；`.page-flight` 类便于清理残留。
- **三处封面网格→详情接上**：专辑（`AlbumsView`）、艺术家（`ArtistsView`）、歌单（`PlaylistsView`）卡片点击捕获起点；详情页（`AlbumDetailView` / 艺术家 / 歌单详情）用 `watch(..., { flush:'post' })` 播放过渡，落定后置 `revealed`，内容（返回钮/头部信息/曲目列表）按 40/80/120ms **错峰浮现**；返回按钮触发 `closing` 轻淡出（180ms）后 `closeDetail()`。艺术家/歌单头图补 `class="header-cover"`。
- 全程 `transform/opacity` only；`--ease-*`/`--dur-*` 令牌；`prefers-reduced-motion` 精简；不触碰既有歌词页飞入。

## 遇到的问题
- `CoverImage` 的模板 ref 拿到的是**组件实例**而非 DOM 元素，直接传给 `playPageTransition` 会类型/运行错；改用 `document.querySelector('.xxx .header-cover')`（`flush:'post'` 后 DOM 已就绪）。
- `pageTransition.ts` 中封面元素可能为 `img` 或 fallback，`currentSrc` 只在 `HTMLImageElement` 上有；三元分支按 `HTMLImageElement` 强转后修掉 TS2339。
