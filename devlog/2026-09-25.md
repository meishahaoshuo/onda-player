### v1.0.0 首个 GitHub Release 发布（本次会话主题）

用户诉求：为桌面端软件发布第一版安装包到 GitHub Releases（此前 Releases 页为空）。

- **重打安装包**：`npm run desktop:build` 全链路通过——vue-tsc 类型检查 ✅、vite build 4.35s、cargo release 6m18s、NSIS 打包成功。产物 `src-tauri/target/release/bundle/nsis/Onda Player_1.0.0_x64-setup.exe`（3,754,432 字节）。旧安装包是托盘浮层改版前打的，期间还移除了 window-vibrancy 依赖，必须重打不能复用。
- **破解了一个大小疑云**：新包 3.75 MB，与 docs/04 9.4 记录的「26 MB 安装包 / 43 MB 主程序」差一个量级，发布前必须查清。排查结论：`Cargo.toml [profile.release]` 在 0.1.0 之后补了 `lto + codegen-units=1 + strip`（`git log -S` 证据），43 MB→10.9 MB 是去符号 + LTO 的正常瘦身，NSIS LZMA 再把 10.9 MB 压到 3.75 MB。产物非缺料：NSIS 头字符串在、tauri 报 Finished 1 bundle、GitHub 上传后服务端 digest 与本地 sha256 逐位一致。**docs/04 9.4 的 26 MB 是旧 profile 时代的数字，不是回归**。
- **发版链路**：本机 `gh` 命令不是 GitHub CLI（另一同名工具），改用 git 凭据管理器里的凭据 + REST API：`git credential fill` 取 token（直接进变量，全程不落日志）→ 建**草稿** Release → 传附件 → PATCH `draft:false` 发布，保证公开瞬间附件已就位。附注 tag `v1.0.0` 先推，指向本次构建对应提交 `7a7a971`。
- **GitHub 资产命名**：附件名中的空格被 GitHub 规范成点（`Onda.Player_1.0.0_x64-setup.exe`），Release 文案已同步改用点号文件名。
- **README 补下载入口**：快速开始章节加「只想用不想配环境 → Releases 下载」引语，开发者步骤保持不变。
- Release 文案包含：安装步骤、WebView2 要求、未签名 SmartScreen 提示、功能一览、SHA-256 校验表、Issue 反馈入口。

### 便携版附件上架（同会话追加）

用户诉求：上传 `src-tauri/target/release/bundle/portable/` 下做好的免安装便携版。该目录已有 9-15 打的 `OndaPlayer-便携版-1.0.0.zip`（结构：`Onda Player 便携版/` 文件夹内改名 exe `Onda Player.exe` + 详细「使用说明.txt」）。

- **旧包不能直接用**：解出包内 exe 做哈希比对——`b60148…` ≠ 当日发布构建的 `5f30fd…`（9-15 之后 Rust 侧删过依赖、exe 被不同流程 patch 过；尺寸碰巧同为 10,987,008 字节，恰好说明看大小不可靠必须看哈希）。同一个 v1.0.0 tag 下两个附件二进制必须一致，故**沿用旧包的结构与说明文案、以当日 app.exe 重新组包**：新 zip 5,017,922 字节，`d9fda577…`；解出包内 exe 复核哈希与 app.exe 逐位一致。
- **PowerShell 5.1 编码坑**：无 BOM 的 UTF-8 .ps1 会被当 ANSI/GBK 读取，脚本里的中文路径全部乱码报「路径中具有非法字符」；给脚本补 UTF-8 BOM 后正常。本会话所有 zip 读写经 System.IO.Compression（条目名 UTF-8 正确）。
- **GitHub 资产名不吃中文**：以 `OndaPlayer-便携版-1.0.0.zip` 上传被服务端清洗成 `OndaPlayer-.-1.0.0.zip`（非 ASCII 被替换成点）。删除该附件（DELETE assets API）后改用 ASCII 名 **`Onda.Player_1.0.0_x64_portable.zip`** 重传（与安装包命名风格一致），digest 复核一致。本地文件名保持中文不变。
- Release 文案改为「安装版 / 免安装便携版」两块 + 校验表补第二行；匿名 `curl -r 0-0 -L` 验证便携包下载 206。
