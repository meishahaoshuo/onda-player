### 收起掉帧修复（三重）
1. **冻结每帧运动**：新增 `freezePageMotion(freeze)`，展开/收起期间 `cancelAnimationFrame` 掉歌词 rAF（`lyricRaf` 逐字卡拉 OK 每帧重排）与鼠标视差 rAF，结束后 `syncLyricRaf()` 按播放态自动恢复。大图缩放本身吃满合成带宽，这两个每帧任务是掉帧主因。
2. **合成层提升**：`.zoom-stage` 加 `backface-visibility: hidden`（原有 will-change），`.zoom-img` 加 `will-change: transform`——避免 80vmin 大图缩放时逐帧重新光栅化。
3. **遮罩独立层**：`.zoom-dim` 加 `will-change: opacity`，全屏遮罩透明度动画不再每帧重绘整屏。
- 实测收起 800ms 内 96 帧：平均间隔 8.3ms、最长 8.8ms、长帧（>32ms）0 个。

## 2. 导入动画封面只来自本次扫描的文件夹（需求反转）

上一轮实现的"全库封面洗牌演出"被否：添加文件夹时动画里出现其他文件夹的封面，要求只演本文件夹。

### 方案（比单纯删掉更好）
- `rescan(onlyRootId?)` 新增可选参数；`addFolder` 改调 `rescan(root.id)` —— **添加文件夹只扫新目录**（也更快），不再重扫全库。
- 新增 `emitRootShow(rootId)`：每个根目录 `scanRoot` 完成后，投喂**该目录下**歌曲的封面（洗牌取 ≤6 张）。因 `flownCoverIds` 去重，实际只补上该文件夹的老歌封面（新歌已由 onBatch 的 fresh 批先飞）。
- 删除 `emitRescanShow`（全库洗牌）与 absorbFlight 的 `BatchKind`/`SHOW_CAP`/`sessionShow` 分账结构，队列回到 `string[][]`。
- 保留 `trimQueueForFinish`（扫描结束裁剪，含在飞批计入预算）——收尾时长优化不回退。

### 两个需求兼顾
- 添加文件夹 → 只扫新目录 → 只有新文件夹的封面 ✓
- 重新扫描 → 逐目录补演 → 即使没有新文件也有动画 ✓（若只保留 fresh 批，无新增文件的重扫会完全没有动画，与上一轮"重扫也要有动画"冲突）

## 3. 音量独立持久化

**根因**（原实现两个漏洞）：
1. `saveNow()` 开头 `if (queue.value.length === 0) return` —— 队列为空时（用户没播歌只调音量）根本不落盘。
2. `restore()` 开头 `if (!settings.autoRestoreQueue) return` —— 「自动恢复队列」关闭时整体跳过，音量跟着不恢复。

**修复**：
- 新增 `VOLUME_KEY = 'player.volume'`，`setVolume` 里 250ms 防抖独立写盘（拖滑杆不写爆 IndexedDB）。
- `restore()` 最前面先恢复音量（不受 autoRestoreQueue 与队列空与否影响），并同步 `lastVolume`；旧数据兼容：独立键不存在时才退回队列状态里的 `state.volume`。

## 4. 歌词设置面板景深开关颜色统一（用户反馈）

**现象**：歌词设置里的「景深模糊」开关开启态在任何歌曲下都是固定的深蓝（全局 `--accent`），而上方滑块把手/对齐按钮颜色随封面派生变化，很突兀。

**根因**：`AppSwitch.vue` 开启态 `background: var(--accent)`——通用组件走全局主题色，没有歌词页的派生令牌概念（scoped 样式里也不会自动继承 `.lyrics-full` 的覆盖逻辑——变量其实继承，只是它引用的是全局 `--accent`）。

**修复**（LyricsFullView 局部 `:deep` 覆盖，不动通用组件）：
- `.app-switch.on` → `var(--lyric-text-active)`（与 `.seg-btn.on` 同令牌）
- hover → `var(--lyric-control-hover)`；开启态 knob → 白色（对应 seg-btn.on 的白字）

验证 verify-switch.mjs **2/2 PASS**：开关开启态背景 = `--lyric-text-active` = `.seg-btn.on` 背景（rgb 数值逐位相等）；≠ 全局 `--accent`（#172554）。
**测试坑**：computed style 返回 `rgb(...)` 而 `getPropertyValue` 返回原始声明（可能是 hex），断言必须解析成数值比较，不能字符串直比。

## 5. 歌词页五项优化 + 封面大图交互方案（用户六条需求）

### 1）暂停时点击歌词 → 跳转并续播
`@click="player.seek(g.time)"` → `onLineClick(g)`：seek 后若暂停态则 `togglePlay()`，并解除手动滚动冻结立即归位。语义：暂停态点歌词 = 想从这句听。

### 2）拖拽归位过慢（两个根因）
- 停手 3s 才解除跟随冻结 → 1.1s；
- 更关键：旧实现只解除冻结、**等下一次换行才滚回**——当前句持续数秒就显得"迟迟不归"。现在 timer 到点主动 `scrollToActive(true)`。

### 3）滚动丝滑
easeOutBack 过冲 c1 1.35→1.2（大幅过冲在小距离换行时是"荡"不是"灵动"），时长 220-460→280-560ms 更从容。

### 4）交错滚动（新功能 + 开关）
换行时以当前行为波源，向两侧按距离 d 错峰（delay d×34ms）轻微上浮/沉落（±7px + 透明度 0.68→1，430ms）。约束：|d|≤8（≤17 个 WAAPI 动画）、波源行不动（有卡拉OK）、reduced-motion 跳过。设置面板新增「交错滚动」开关（默认开，`settings.lyricStagger`）。

### 5）入场过渡
封面落地（flyActive true→false）后，歌词栏(--i:1)/标题(--i:0)/进度条(--i:2)/控制区与工具组(--i:3)按 `--i` 错峰 70ms 上浮（16px + 淡入，560ms）。CSS：`.fly-active .enter-item{opacity:0}` + `:not(.fly-active) .enter-item{animation enter-up both}`。封面本体不参与（有 FLIP 飞入）。

### 6）封面大图交互动效 → 方案演示页
用户看不到 show_widget（历史坑），做独立 `preview/cover-fx-demo.html`（canvas 模拟封面 + 四方案实时交互）：A 悬浮视差（3D 倾斜+高光流动）/ B 触水生涟（划过泛涟漪点击炸三圈，与"澜"水意象同根）/ C 光尘流溢（粒子飘落）/ D 惯性缩放（滚轮阻尼缩放+拖拽平移，看封面细节）。待用户选定后实现。
