## 3. 音量独立持久化

**根因**（原实现两个漏洞）：
1. `saveNow()` 开头 `if (queue.value.length === 0) return` —— 队列为空时（用户没播歌只调音量）根本不落盘。
2. `restore()` 开头 `if (!settings.autoRestoreQueue) return` —— 「自动恢复队列」关闭时整体跳过，音量跟着不恢复。

**修复**：
- 新增 `VOLUME_KEY = 'player.volume'`，`setVolume` 里 250ms 防抖独立写盘（拖滑杆不写爆 IndexedDB）。
- `restore()` 最前面先恢复音量（不受 autoRestoreQueue 与队列空与否影响），并同步 `lastVolume`；旧数据兼容：独立键不存在时才退回队列状态里的 `state.volume`。

## 4. 歌词设置面板景深开关颜色统一（用户反馈）

## 19. 顶部「颜色断层」真正根治（浅色主题隐藏氛围光斑）

用户四张浅色主题截图（歌曲/我喜欢的音乐/最近在听/文件夹）断层依旧。诊断实验（diag-band.mjs）发现 headless 下 blobs=[]——**上轮「灰调取色过滤」只治了灰封面，彩蓝灰色调封面依旧产生光斑**：光斑是 opacity 0.15 的径向晕染，白底上呈灰带观感，且被 sticky 表头的不透明白底（bg-base）横切出锐利直线——直线即「断层」。用户两次反馈的本质诉求：**不想要顶部任何晕染色块**（白底极简风格冲突）。

根治：App.vue `[data-theme='light'] .ambient-layer { display: none }`——浅色主题整体隐藏氛围光斑；深色主题深底上晕染协调，保留。设置页「封面氛围光」开关语义不变（深色生效）。

**验证坑（老坑再踩）**：verify-ambient.mjs 首跑光斑层 exists:false——不是 CSS 问题，是 2s 测试音频自动切歌切到无封面曲目、v-if（coverId）自然为 false。playAt 后立即 toggle 暂停钉死即过。2/2 PASS（浅色 display:none / 深色 display:block）。
