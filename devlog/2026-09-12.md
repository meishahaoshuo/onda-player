**迭代轨迹**（用户边看 HMR 实时效果边反馈）：

   - 吸附类元素 top 统一走 `--list-sticky-top`（view-body 内 = 顶栏高度；详情覆盖层/文件夹右列等独立宿主默认 0，FoldersView 曾加覆盖后随表头移除一并删掉）；设置页左列导航同步改用该变量。
3. 用户随即改主意：「直接去掉标题艺术家这个列表表头吧」——SongList（歌曲/我喜欢的/专辑与艺术家详情/搜索/文件夹右列共用）与 ChartsView 的列名表头整个删除，行自身 grid 对齐不变；顺带清理全部相关样式与过时注释（含 FoldersView 的 sticky 覆盖）。

**最终形态**：顶栏 = 悬浮普通磨砂条（内容从其下穿过）；列表无列名表头，行直接从顶栏磨砂底下滚过；设置页导航仍吸在顶栏下缘（`--list-sticky-top` 机制保留）。

**验证**：`npm run build`（vue-tsc）通过；观感由用户在 dev server（HMR 实时）直接确认。

## 遇到的问题

1. **表头液态玻璃必然带出「断层」**：滚动宿主（view-body）在顶栏下方，行只能在被表头覆盖的区段里露出玻璃质感，顶栏是页面底色——材质在两者交界处硬切。解法不是给顶栏也涂同一材质（顶栏 backdrop 里没有行，观感仍对不上），而是把顶栏变成悬浮层、让行物理上从它底下穿过。
2. **悬浮顶栏吃掉 sticky 基准**：view-body 顶边到了页面 y=0，`top: 0` 的吸附元素会钻进顶栏背后。引入 `--list-sticky-top`（.content 定义 `--head-h`，view-body 换算），各吸附位一处变量全局联动。
3. **ChartsView 去表头时手滑产出重复 `.chart-row` 规则**，下一笔编辑立即收成单条。

## 4. 歌曲页「定位悬浮球」（会话 52 追加；样式经用户四选一：玻璃圆球 + 按需浮现）

**交互**：正在播放的行滚出滚动宿主可视区时，右下角（播放条上方）浮现一颗 44px 磨砂玻璃圆球（中心新增 `locate` 十字准星图标，外圈一圈当前封面明亮色的 2px 细环做呼吸光晕，取色走 `paletteCache.brightColors`、失败回落 `--accent`）；点击平滑滚动把该行带回视野中央，行回到可视区后球自动淡出。行在视野内不显示；未播放/播放上下文不在全库列表时永不显示。`prefers-reduced-motion` 下光晕静止、滚动与浮现过渡降级为即时。

**实现（`SongsView.vue` + `icons.ts`）**：
- 滚动宿主 = `closest('.scroll-host')`（外层滚动架构）；行号 = `sortedSongs.findIndex(currentPath)`，行顶偏移 = `.song-list` 与宿主的 rect 差 + `index × 56`（VirtualList 的 spacer 行高固定，纯算术免测量）。可视判定带 ±4px 容差，宿主 scroll（passive）/resize/播放切歌三处触发重测。
- 球 `position: fixed; right: 24px; bottom: 112px`（标准条 80 / 胶囊 16+66 上方都有净空）；fixed 而非 absolute 是因为 `.songs-view` 在滚动宿主内会随内容长高。`z-index: 4`：内容之上、详情覆盖层(5)/播放条(6)之下——详情/搜索/歌词页一开就被盖住或随 SongsView 卸载，无需额外处理。
- 玻璃材质 = `--glass-bg/--glass-blur/--glass-border/--glass-highlight`（与队列面板同语言）；浮现 = `Transition name="fab"` 200ms 缩放淡入。

**验证**（`devlog/.shots-2026-09-12/verify-fab.mjs`，CDP + 测试桥 30 首歌）：行在视野内 `fab: false` ✓；滚到 900px 后浮现且 `::after` box-shadow 已是封面取色 `color(srgb .85 .63 .35 / .4)` ✓；点击后 1.2s 内宿主 scrollTop 回 0、球自动消失 ✓；`npm run build` 通过。

## 5. 悬浮球定稿「澜·涟漪」：28px 液态玻璃 + 光感粒子（会话 52 续；样式经对比稿四选一）

用户在对比稿（`devlog/.shots-2026-09-12/fab-styles.html`，真实令牌 1:1、可切深浅主题、悬停可试交互）四方案（A 涟漪 / B 声核均衡器 / C 光尘珠 / D 进度环）中选 **A**，并要求叠加**液态玻璃**与**光感粒子**。最终形态替换掉首版 44px 磨砂球：

- **尺寸 44 → 28px**；材质换播放条 `material-liquid` 同语言：深色 = 白纱 3/1.5/2.5% + `blur(20px) saturate(3.6) brightness(1.2)` + 亮顶缘内高光 + 白 22% 描边；浅色 = 白纱 8/4/6.5% + `blur(18px) saturate(3.1) brightness(1.05)` + 黑 10% 描边（scoped `:global([data-theme='light'] …)`）。
- **涟漪**：球心 6px 封面色光珠（`--halo-c` = `paletteCache.brightColors` 首色，失败回落 `--accent`），两道 1.5px 封面色细环 2.6s 交错从珠心外扩至 2.1 倍淡出（`lf-rip`）——品牌「澜」的水波意象，不再用图标。
- **光感粒子**：球内三粒 1px 光尘（`box-shadow` + 全局 `--dust-blur/--dust-spread/--dust-bloom-color` 令牌）4.5–5.5s 慢漂；浅色主题白尘不可见，改 `color-mix(halo-c 80%)` 封面色微尘。基础 transform 即静态散布位，`reduced-motion` 关动画后不叠在球心（此时涟漪隐藏、光尘静布）。
- 定位逻辑不变（按需浮现/点击回中/自动隐藏）。

**验证**（`verify-fab.mjs` 更新断言重跑）：浮现时 `size: 28`、球心 `rgb(216,161,88)`（封面琥珀）、`lf-rip` 动画运行、3 粒光尘；点击后滚回 0、球消失；`npm run build` 通过。实境截图 `fab-ripple-visible.png`。

## 8. 悬浮球浅色主题适配修复（会话 52 续三）
