## 补记：同一会话后半段的四项改动

> 这几项改了代码也截了图（都在 `.shots-2026-09-15/`），但当时只提交了 logo 那一半，一直悬在工作区里。2026-09-19 接手时补记并提交。

### 1. 托盘改自绘浮层菜单（取代系统托盘菜单）

系统原生托盘菜单样式跟着系统走、放不下封面与曲目信息，改成**自绘浮层**——Rust 侧新建一个 `tray-menu` 窗口，加载 `index.html?tray=1`，由 `src/tray.ts` 挂载一个**独立的小 Vue 应用**（不跑启动过场、不建 Pinia、不注册 PWA）。

- **一个入口两种窗口**：`main.ts` 按 `?tray=1` 分流。不分流的话浮层会走完整开机流程，`primeWindow()` 会把浮层自己当成主窗口去定位并 show，菜单直接错位。
- **三个方向的通信**：主窗口 → 浮层用 `tray_menu_state` 推状态（Rust 缓存最近一份，右键展开时回放——浮层平时隐藏，只靠广播会漏掉「打开之前」的那次更新）；浮层 → 主窗口广播 `tray://playpause|prev|next|favorite|go`，由 `desktop.ts` 转成 `onda:tray-*` DOM 事件交 App.vue 调 store；浮层 → Rust 走 `tray_show_main` / `tray_quit` / `tray_menu_hide` / `tray_menu_resize`（高度由内容 ResizeObserver 回报，窗口随内容长）。
- **封面不跨窗口搬运**：两个 webview 同源共用 IndexedDB，状态里只传 `coverId`，浮层自己去取图。
- **交互约定**：播放控制/收藏点完**不收起**菜单，状态由主窗口推回来就地刷新；只有跳转（设置）才收起，且先 `showMainWindow()` 再导航——不然状态改了用户也看不到。
- 浮层**固定浅色**（不跟随应用/系统主题），窗口 `transparent` + CSS 画两层阴影（窗口自身关掉了系统阴影）。
- 预热排在启动过场收尾之后 2500ms，不给开机路径添负担。
- capabilities 的 `windows` 加上 `tray-menu`。

### 2. 窗口「透出桌面 + Acrylic」整体回退

上一版做了 `transparent: true` + Rust 侧 Acrylic + 页面基底 76% 半透明。真机量下来那 24% 的缝隙底下压着的是**不透明白**（窗口材质没真正成形），深色模式页面底色被抬到 **#454545**——恰好是 `0.76 × #0a0a0a + 0.24 × #ffffff`，分毫不差；比侧栏/面板这些玻璃层还亮，明暗层次整个反掉。

用户决定暂不做这个特性：窗口恢复不透明，body 直接铺实色 `--bg-base`，各层关系随之恒定（基底最暗 → 面板/顶栏依次递亮）。删除 `html.desktop-glass body` 规则、`set_window_effect` 命令、`tauri.conf.json` 的 `transparent: true`。

### 3. 修 html 首帧底色不随主题（#454545 的另一半根因）

`index.html` 的防闪脚本只在**页面加载时**写一次 html 内联背景，运行中切主题不会重写——深色模式下 html 就永远停在加载时那块白上，页面基底只要带一点透明度就会把它透出来。修法：在 settings store 的 `watchEffect` 里与 `data-theme` 一起写 `document.documentElement.style.backgroundColor`，保证两层底色永远同步。

### 4. 视觉修正

- **深色 + 液态玻璃的胶囊播放条摘掉外框高光**（用户反馈）。实测那圈高光由两条声明叠成：`border: 1px solid rgba(255,255,255,.38)`（上106/下107/左117/右109，贯通四边）+ `inset 0 1.5px 1px rgba(255,255,255,.8)`（上205/左92/右81，pill 圆角让它绕了一圈）。逐层隔离确认后两条都摘掉，边框改 `transparent` 保留 1px 占位——胶囊是 border-box，这样内侧排布与圆角轮廓一像素都不动。浅色主题不改。
- **主题色预设换新**：旧 7 键（网易云红/QQ音乐绿/…）换成一整套「同一深度」的颜色——亮度统一 44~47%、饱和度 30~48%，命名走传统颜料（黛紫/绛红/琥珀/松绿/石墨）。刻意压到 5 个，加上默认与自定义正好 7 键 = 一排不换行；实测原内边距下总宽 534px > 容器约 510px 会折行，把间距与内边距各收紧一档留出余量。自定义按键的色相环跟着新色板走（不再写死旧色）。
- 新增 `power` 图标（退出应用），与「关闭窗口」的 `close` 区分。
