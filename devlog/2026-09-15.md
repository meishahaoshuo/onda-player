## 今日完成

- **品牌 logo 定稿方案 C 并全量铺开**
  用户反馈「上下两条波浪与中间那条粗细不一样、搭配不和谐」→ 先统一线宽到 88，再反馈「三条搭配起来还是不和谐」→ 给出三个候选（A 两端收拢 / B 振幅递减 / C 疏朗均衡），用户选定 **C**，随后要求把所有有图标的地方（含启动动画）全部替换。

  **诊断出的三个量化病灶**（原版）：
  | 问题 | 实测 |
  |---|---|
  | 间隙比笔画还窄 | 间隙:笔宽 = 0.70 : 1（62 : 88） |
  | 相邻波浪起伏范围重叠 10px | 振幅 ±80，一圈 160 > 间距 150 → 三条互相咬合、没有呼吸 |
  | 三条起止 x 相同、同相同振幅 | 纯复制粘贴，两端齐平形成竖直「栅栏」 |

  **方案 C 的改动**：振幅 ±80 → **±64**，中心线间距 150 → **168**（间隙比 0.70 → **0.91**），线宽统一 88。三条起伏范围不再重叠，净空 40px。墨迹 692×524 → **692×552**。

## 遇到的问题

- **差点漏掉启动动画**：`BootSplash.vue` 自己内联了一套波浪常量（`WAVE_D` + `LAYERS`），不 grep 源码根本发现不了。已把「logo 全量铺开清单」写进记忆，下次照单执行。
- **差点漏掉桌面端应用图标**：`src-tauri/icons/` 那套（任务栏/托盘/安装器）还是旧几何。`tauri icon` 的 INPUT 接受方形 SVG，可直接用 `onda-icon.svg` 重生成。
- **验证脚本自身有 bug**：第一版量墨迹用了 `sharp().removeAlpha()`，透明底被抹成黑、墨迹量成整幅 1024×1024，误报「不符」。**透明背景必须走 alpha 通道**。修正后结论：启动动画 logo 与品牌源文件**逐像素完全重合，最大 alpha 差 = 0**。
- **口算墨迹尺寸错了两次**（先说 692×364、又算成 548，真值是 692×524 —— 都漏算/算错了波浪本身的起伏）。教训：**几何量得出来就别口算**。
