## 4. 黑洞三项反馈修订（用户反馈修订三）
1. **黑洞滞留修复**：旧版扫描结束后固定 `wait(flightMs+320)` ≈1.2s 才坍缩；改为 **`inFlight` 在飞计数**（flyOne +1 / cleanup -1），`waitUntilIdle()` 轮询等实际吸完（60ms 步进、上限 2.6s）后 +90ms 让落点脉动走完即坍缩。实测扫描结束→黑洞消失 **0ms 延迟**。
2. **卡顿修复（根因：逐帧 filter blur）**：封面 keyframes 里的 `filter: blur()` 逐帧插值会让浏览器每帧重新光栅化（项目既有教训「blur 不参与 transition」的同族问题）——**移除**，"被卷入"改由螺旋收敛+透明度收束表达；`will-change` 精简为 transform/opacity；**黑洞各旋转层也去掉静态 filter blur**（halo/disk 的 blur 在无限旋转下每帧重算）——conic/径向渐变本身连续，靠渐变过渡就够柔；旋转层加 `willChange: transform` 走纯合成。封面尾段提前 8% 移除（已不可见，早让出图层）。
3. **样式再精修**：吸积盘加 **repeating-conic 细密物质流条纹**（丝状质感）+ 内层白热混色；新增**内辉光**层；光子环加宽加辉光过渡；事件视界加 inset 高光与双层 accent 外发光；halo 改大范围纯径向弥散。全 accent 令牌。
验证 verify-blackhole.mjs 10/10 PASS：扫描结束→黑洞移除延迟实测 0ms；全程采样 140 帧飞行元素与黑洞各层 filter 均为 none；生命周期/限流/reduced-motion 回归通过。

## 10. 四项体验修复（用户反馈：全库封面 / 收尾时长 / 丝滑水流感 / 水波颜色）

### 1）添加文件夹/重扫时演出全库封面（library.ts + absorbFlight.ts 批次分账）
- 根因：添加文件夹时 `emitRescanShow` 投的全库批与新入库批抢同一个 SESSION_CAP（24），先到先得会把新歌挤掉；且旧库无封面时全库批为空，用户只看到新文件夹的封面。
- 方案：批次带 `kind`（`fresh` 新入库 / `show` 全库库存演出），队列取批时 **fresh 优先**；`SHOW_CAP = 12` 独立额度，两本账互不挤占。`emitRescanShow` 改投 2 批 `show`。

### 2）收尾时长（trimQueueForFinish 扫描结束裁剪）
- 根因：扫描结束不清队列 → 大库时未消费批堆积，进度条走完动画还在飞 8s+。
- 方案：scanning true→false 时把队列裁剪为「1 批 fresh + 1 批 show」，且 **已在飞批计入预算**（`budget = inFlight > 0 ? 1 : 2`，否则实际会飞 3 批 ≈4.1s）。同时 BATCH_GAP 420→240、FLIGHT_MS 860→780。实测 40 首收尾 4124→**2837ms**。

### 3）飞行「一顿一顿」根因与丝滑化（flyOne 轨迹重写）
- 根因一：极坐标螺旋只有 **6 个采样点**，段间线性插值出折线与速度突变；根因二：每个 keyframe 独立 `cubic-bezier(0.45,0,0.75,0.6)` ease-in，每段末尾减速、下段起点又从零加速，速度不连续。
- 方案：`TRAIL_SAMPLES = 32` 密采样；缓动（0.12t + 0.88t²，起步即有速度、越近漩涡越快）**烘焙进采样点**，整体 linear 插值；**朝向跟随螺旋切线**（数值差分求切线角，±180 展开防跳变）+ 少量自转 = 叶子被水流卷着走的翻滚感；中段沿切线 `scale(1+drag, 1/drag⁻¹)` 轻微拉伸/压缩表现水流拖拽。全程仅 transform/opacity，性能铁律不破。

### 4）歌词页水波发黑（palette.ts 新令牌 + LyricsFullView 重做）
- 根因：`--lyric-accent` 是 `darkenTo(main, bg, 对比度)` 的**文字对比色**（朝黑压暗），做水波描边必然发黑。实测同封面 accent `rgb(70,65,28)` vs 封面原色 `rgb(202,192,124)`。
- 方案：新增特效令牌 `--lyric-wave`（主色向白混 28%）/ `--lyric-wave-soft`（混 50% + alpha 0.55），`main.css :root` 同步默认值（歌词页两主题同值）。
- 效果重做：2 圈黑环 → **3 层涟漪**（scale 1.44/1.8/2.16，delay 80/195/320ms，opacity 递减）+ **1 层色场光晕 `.zoom-bloom`**（主色径向渐变炸开）；形状从封面圆角 `border-radius: 18px` WAAPI 插值到 `50%`（水波脱离源头后变圆）；环带内加 radial 渐变边缘柔光（代替 box-shadow 防重绘）。
