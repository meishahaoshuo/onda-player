## 1. 文件夹添加「封面吸入黑洞」动画

### 数据流
- `scanner.ts`：`scanRoot` 增加第 5 个可选参数 `onBatch?: (batch: SongRecord[]) => void`，`flushWrites` 在 `db.putSongs` 后回调本批新入库记录（skipped 的天然不进；finally 收尾 flush 自动报尾批）。
- `library.ts`：`scanBatchSink` 槽位 + `setScanBatchSink(fn)` 导出；`rescan` 调 scanRoot 时转发——批内 coverId 去重（同专辑共享一个 coverId）后非空则 `scanBatchSink?.(ids)`。store 不 import 动画模块（防循环依赖）。
- 新建 `src/services/absorbFlight.ts`（约 270 行）：App onMounted `installAbsorbFlight()` 注入 sink。

### 动画设计（优雅弧线 + 微螺旋）
- 常量：FLIGHT_MS 840 / LAND_AT 0.72 / STAGGER 120ms（±40 抖动）/ 封面 40px / BATCH_CAP 6 / SESSION_CAP 24 / BLUR_MAX 2.5px / SPIN_MAX 38° / SOURCE_TIMEOUT 300ms。
- 起飞点：`setOriginFromEvent(e)` 在系统文件夹选择器打开前捕获触发按钮 rect（FoldersView 空态/工具栏与 SettingsView 的添加按钮 emit 均带 $event）；无事件兜底 = 屏幕左侧中部随机散布（覆盖两个触发视图）。
- WAAPI 7 offset：0 原点浮现（scale 0.7）→ 0.14 浮起 → 0.38 弧线过拱顶（arc=clamp(距离×0.16, 48, 110)）→ 0.58 滑入收偏（横向内收 = 螺旋切向分量）→ 0.72 触达（scale 0.42 / rotate ±38° / blur 1.5）→ 0.88 螺旋过冲（scale 0.18 / blur 2.5 / op 0.35）→ 1.00 完全吸入（scale 0.1 / op 0）。螺旋 = 横切向偏移 + 角度单调增 + 尺度加速衰减三者叠加，无强潮汐变形。
- 落点：dipPlayerBarLite（translateY 1.6px / 260ms，180ms 节流防批内连抖）+ 批末张落定后 120ms `popPlayerCover()`（复用 coverFlight 导出）。
- 防线四道闸门（enqueue 直接弃，进度条兜底无损失）：prefers-reduced-motion / `ui.dolly !== 'idle'`（页面过渡互斥）/ `ui.lyricsOpen`（歌词页盖住播放栏会穿模）/ `document.hidden`。
- 限流：会话累计 ≤24 张（超出只 pop）、每批 ≤6、同 coverId 会话级去重；`peekCoverUrl` 同步命中优先、未命中 `coverUrl` 竞速 300ms（动画不拖扫描节奏）。
- 收尾：watch `library.scanning` true→false 清 queue/sessionFlights，下次扫描开始清 flownCoverIds；lite 档（≤2 核）时长 ×0.75、stagger 90ms。
- `div.absorb-flight` 不复用 `.cover-flight` 类名——coverFlight 的清理 `querySelectorAll('.cover-flight')` 会误删。
- DEV 探针 `window.__absorbDebug()`（queueLen/flying/sessionFlights/flown），生产构建不含。

## 2. 主题色预设色板换新（现代鲜亮 8 色）

- 旧 7 色偏浊（#0e9488/#2f7d5c/#c2841d/#c04a6e/#7a5cd0/#5b6470/#9a3b52）→ 新 8 色：**靛蓝 #5865f2 / 天青 #0284c7 / 翡翠 #0ca678 / 琥珀 #d97706 / 珊瑚 #ef5350 / 玫红 #e64980 / 紫罗兰 #8b5cf6 / 石墨 #64748b**。
- 选色约束：settings 的简单亮度（非 gamma 校正，阈值 0.62 决定 accent-text 黑/白）——8 色全部落在 0.42~0.52，统一白字且离阈值 ≥0.10；不用 emerald-500/sky-500/amber-500 等 500 系原值的原因：白底对比不足或亮度临界造成文字色漂移。
- `ACCENT_PRESETS` 改 `{ c, name }[]` 结构，swatch title 显示中文名；「默认海军蓝」swatch（setAccentColor('')）与 input[type=color] 自定义取色器原样保留；布局 10 swatch ≈ 410px < 可用 636px 一行放得下。

### 验证
- 9 swatch（默认+8）+ 自定义取色器渲染正确；八色依次点击 inline `--accent` 精确命中、`--accent-text` = #ffffff、localStorage 同步；默认按钮回海军蓝（inline 清空）。
- 踩坑：sw.click() 后同帧读 inline 变量太早（watchEffect 异步写）需 sleep 150ms；`style.background` 返回 rgb 串不含 hex，按 title 中文名定位 swatch。
