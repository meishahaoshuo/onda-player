## 2. 落点改为「悬浮建库黑洞」（用户反馈修订）
用户反馈吸入落点应有黑洞本体，选定「悬浮建库黑洞」方案 + 封面从四面八方汇聚：
- **黑洞元素**：扫描批次首次入队时在播放栏上方中央浮现（fixed bottom 播放栏高+28，76px，z 45 低于歌词页 50 被自然遮盖）——accent 色 conic 吸积盘（blur 3px + 径向 mask 成环，WAAPI 无限旋转 5.2s）+ 暗核（radial 渐变事件视界 + accent 光晕），浮现 Q 弹 420ms。
- **四面八方汇聚**：废除 origin/按钮定位链路（App/两视图的 $event 传递回退），起飞点 = 黑洞周围随机环带（半径 230~410px，8 次尝试保证落视口内，兜底缩小钳入）。
- **极坐标螺旋**：keyframes 由极坐标采样生成——r = r0×(1-t²)（近核急缩）、θ = θ0 + spinTotal×t²（越近转越快，总绕行 110°~180° 随机方向）、scale 0.92→0.14、blur 2.5t²；封面绕黑洞旋入而非直线飞。
- **落点**：播放栏 dip/pop 移除，改黑洞自身脉动（scale 1.07 / 240ms，180ms 节流）。
- **生命周期**：扫描会话首批入队创建；scanning false → 弃未消费批、泵空 + 最后一张飞完后坍缩（吸积盘加速 + scale 0.22 旋出消失）；`bhCollapsing` 防重建竞态。
- 验证 verify-blackhole.mjs 8/8 PASS：黑洞出现、封面与黑洞同帧、坍缩移除、二次会话重现、限流、reduced-motion。
- **验证环境坑**：此 headless 实例 `prefers-reduced-motion` 实测默认 **reduce**（会拦整个动画）——验证脚本必须 `Emulation.setEmulatedMedia` 显式覆盖 no-preference；轮询判停必须「先见过 scanning=true 再允许 break」，否则 addBulkSongs 写文件阶段（scanning=false 无黑洞）第一圈就立退造成假失败。

## 4. 黑洞三项反馈修订（用户反馈修订三）
1. **黑洞滞留修复**：旧版扫描结束后固定 `wait(flightMs+320)` ≈1.2s 才坍缩；改为 **`inFlight` 在飞计数**（flyOne +1 / cleanup -1），`waitUntilIdle()` 轮询等实际吸完（60ms 步进、上限 2.6s）后 +90ms 让落点脉动走完即坍缩。实测扫描结束→黑洞消失 **0ms 延迟**。
2. **卡顿修复（根因：逐帧 filter blur）**：封面 keyframes 里的 `filter: blur()` 逐帧插值会让浏览器每帧重新光栅化（项目既有教训「blur 不参与 transition」的同族问题）——**移除**，"被卷入"改由螺旋收敛+透明度收束表达；`will-change` 精简为 transform/opacity；**黑洞各旋转层也去掉静态 filter blur**（halo/disk 的 blur 在无限旋转下每帧重算）——conic/径向渐变本身连续，靠渐变过渡就够柔；旋转层加 `willChange: transform` 走纯合成。封面尾段提前 8% 移除（已不可见，早让出图层）。
3. **样式再精修**：吸积盘加 **repeating-conic 细密物质流条纹**（丝状质感）+ 内层白热混色；新增**内辉光**层；光子环加宽加辉光过渡；事件视界加 inset 高光与双层 accent 外发光；halo 改大范围纯径向弥散。全 accent 令牌。
验证 verify-blackhole.mjs 10/10 PASS：扫描结束→黑洞移除延迟实测 0ms；全程采样 140 帧飞行元素与黑洞各层 filter 均为 none；生命周期/限流/reduced-motion 回归通过。
**验证坑**：性能采样断言要与动画并行跑（watchRes 轮询内嵌 filter 采样），事后单独采样会扑空。
