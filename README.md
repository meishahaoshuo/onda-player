## ✨ 特性

- **本地音乐库接入**：选择本地音乐文件夹（支持多文件夹），递归扫描并解析标签；浏览器「记住」授权，重开页面确认一次即可恢复，文件不复制。
- **增量扫描**：按「路径 + 文件大小 + 修改时间」判断变化，未变化的文件不重复解析；扫描过程显示进度、可取消、不阻塞界面。
- **支持的音频格式**：MP3 / FLAC / OGG / OPUS / WAV / M4A（APE 等浏览器不支持的格式自动跳过）。
- **多视图浏览**：歌曲 / 专辑 / 艺术家 / 文件夹 / 歌单 / 排行榜 / 最近在听 / 搜索。
- **全屏歌词**：增强型 LRC 逐字点亮（Apple Music 式卡拉 OK）、双语歌词合并、点击任意行跳转进度、逐行景深模糊；字号 / 字重无级调节、居中对齐切换、可调模糊背景，切歌时背景平滑过渡。
- **播放内核**：播放 / 暂停 / 上下曲 / 进度拖拽 / 音量；四种播放模式（顺序 / 列表循环 / 单曲循环 / 随机）；可见可跳转的播放队列；MediaSession 媒体键可控；刷新后恢复队列、当前曲目、进度、音量、播放模式。
- **歌单**：新建 / 重命名 / 删除、自定义排序（添加顺序 / 歌曲名 / 艺术家 / 专辑 / 播放次数 / 时长）、手动设置封面、多封面拼贴；全局歌曲右键菜单（播放 / 下一首播放 / 收藏 / 添加到歌单 / 查看专辑 / 查看艺术家 / 移除）；大号多选批量添加歌曲弹层。
- **我喜欢的音乐**：播放条一键爱心收藏，IndexedDB 持久化。
- **排行榜**：按播放次数排名（听满 30s 或 50% 进度计 1 次），金银铜名次徽标。
- **设置**：深 / 浅 / 跟随系统三主题、自定义强调色、可录制的快捷键、封面氛围光、歌词外观（字号 / 字重 / 对齐 / 景深模糊）、数据管理（清空统计 / 收藏 / 全部资料）。
- **隐私优先**：纯本地 IndexedDB 存储，无任何遥测、无 CDN、零网络请求。
- **PWA**：自带 `manifest.webmanifest`，可安装到桌面 / 移动主屏。

## 🚀 快速开始

> 前置：Node.js 20+，Chrome / Edge 最新版（依赖 File System Access API）。

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器 → http://localhost:5180
npm run build      # 类型检查（vue-tsc）+ 生产构建到 dist/
npm run preview    # 预览构建产物
```

日常使用可双击根目录 **「启动播放器.vbs」** 启动静态服务（端口 5181）打开 `dist/`。

## 📖 使用说明

1. 通过浏览器以 `http(s)` 访问，**`file://` 直接打开无效**（依赖 File System Access API）。
2. 首次进入在「设置 → 音乐文件夹」授权本地音乐文件夹；浏览器会记住授权，重开页面确认一次即可。
3. 支持多文件夹；扫描按「路径 + 大小 + 修改时间」做增量，未变化的文件不重复解析。
4. 大型歌库（数千首）列表采用虚拟滚动，浏览不卡顿。

## 🔒 隐私

所有歌曲与元数据仅存于本机浏览器 IndexedDB，**不上传任何内容，无任何网络请求**。

## ⚠️ 浏览器要求

需 Chrome / Edge 最新版（依赖 File System Access API，Safari / Firefox 完整功能受限）。
