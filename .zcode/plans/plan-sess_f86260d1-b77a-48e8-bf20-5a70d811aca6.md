# 本地音乐播放器（网页版 Vue 3 + Vite）— 分阶段开发计划

目标：做一个类似 Salt Player 的网页版本地音乐播放器：侧边栏音乐库 + 底部播放条 + 全屏双语歌词页（封面模糊背景），深色/浅色切换 + 磨砂半透明界面。通过浏览器文件夹授权读取本地音乐（Chrome/Edge），文件不复制。

## 一、项目管理机制（第 0 阶段建立）

**版本控制**：`git init` + `.gitignore`（node_modules/dist），每个阶段完成并验证后提交一次，出问题可回滚。

**docs/ 文件夹**（开发标准文件，作为唯一事实来源）：
| 文件 | 内容 |
|---|---|
| `docs/01-需求说明.md` | 功能需求清单（对照三张截图逐条列验收标准）、非功能需求 |
| `docs/02-技术方案.md` | 技术栈、依赖清单、架构、IndexedDB 数据模型、目录结构 |
| `docs/03-设计规范.md` | 深浅色配色变量表、磨砂面板参数（透明度/模糊半径）、字体字号、布局尺寸、组件状态样式 |
| `docs/04-开发步骤.md` | 分阶段计划、每阶段验收标准、当前进度状态标记 |

**devlog/ 开发日志文件夹**：
- 每天一个文件 `devlog/YYYY-MM-DD.md`，模板：今日完成 / 遇到的问题 / 明日待办
- 机制固化：**每次开发会话结束时必须更新当天日志并提交 git**，此规则写入 AGENTS.md 强制执行

**AGENTS.md**（AI 工作指引，项目根目录）：项目简介、必须先读的标准文件路径表（docs 四个文件）、工作流程规则（开发前读 04-开发步骤 确认当前阶段 → 开发 → 浏览器验证 → 更新 devlog → git commit）、运行命令（npm run dev/build）、禁止跨阶段大批量开发等约束。另建 `CLAUDE.md` 指向 AGENTS.md（内容一致，兼容不同 AI 工具）。

## 二、技术选型

| 领域 | 方案 |
|---|---|
| 框架 | Vue 3 + Vite + TypeScript + Pinia |
| 文件接入 | File System Access API（选文件夹并「记住」句柄，重开确认一次授权） |
| 音频 | HTMLAudioElement（MP3/FLAC/OGG/OPUS/WAV/M4A；APE 不支持，浏览器解码限制） |
| 元数据 | `music-metadata`（标题/艺术家/专辑/封面/采样率/位深） |
| 存储 | IndexedDB（`idb`）：文件夹句柄/歌曲缓存/封面 blob/歌单/播放状态/设置 |
| 系统集成 | MediaSession API（Windows 媒体浮窗/媒体键） |

## 三、分阶段开发步骤（每阶段一个可验证的小闭环）

**第 0 阶段：项目初始化**
git init、Vite 脚手架、依赖安装、创建 docs/ 四个标准文件、devlog/ 模板、AGENTS.md 与 CLAUDE.md、首次提交。验收：`npm run dev` 打开默认页。

**第 1 阶段：主题体系 + 布局骨架**
深浅色 CSS 变量体系（跟随系统/手动切换/持久化）、FrostedPanel 磨砂组件、整体布局：自定义侧边栏（占位菜单）+ 底部播放条（占位控件）+ 自定义标题栏区域。验收：深浅色一键切换生效，磨砂效果可见，对照截图布局。

**第 2 阶段：文件夹接入 + 音乐库**
文件夹选择与句柄持久化、递归扫描音频文件、music-metadata 解析标签、封面提取缓存到 IndexedDB、扫描进度显示、增量更新（路径+大小+mtime）、歌曲列表页（序号/音质徽标/标题/艺术家/专辑/时长、虚拟滚动）。验收：选择真实音乐文件夹后列表完整显示、刷新后重新授权即可恢复、二次扫描明显加快。

**第 3 阶段：播放内核**
播放/暂停/上下曲、进度条拖拽、音量、播放模式（顺序/列表循环/单曲/随机）、播放中歌曲高亮、MediaSession 集成、退出时保存队列/进度/音量并恢复。验收：完整播放一轮各种模式无异常，媒体浮窗可控。

**第 4 阶段：专辑/艺术家/文件夹/曲风页**
四个聚合视图 + 专辑详情页（大封面头部、统计信息、播放/随机按钮、碟片分组曲目）。验收：从歌曲列表可跳转到对应专辑/艺术家，数据正确。

**第 5 阶段：歌单**
新建/重命名/删除歌单、添加歌曲、拖拽排序、歌单播放。验收：建歌单→加歌→播放→重开不丢。

**第 6 阶段：全屏歌词页**
同目录 .lrc 读取解析、时间戳相同的翻译/罗马音行合并分组、封面铺满+大半径模糊背景、封面倒影、当前行放大高亮+自动居中滚动、点击歌词行跳转、深浅色适配。验收：对照截图 1 效果。

**第 7 阶段：设置页 + 收尾**
音乐文件夹管理（增删/重扫）、主题设置、`npm run build` 产物本地预览验证、整体回归测试、最终提交。

每个阶段完成前运行 `npm run dev` 在浏览器实际验证，并对照 docs/01-需求说明.md 的验收标准；阶段结束更新 devlog 并 git commit。
